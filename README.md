# Agent Patterns

A practitioner's reference of patterns, techniques, and workflows for engineers building with AI coding assistants. Tool-agnostic principles with practical coverage of Claude Code and GitHub Copilot.

**Website**: [agentpatterns.ai](https://agentpatterns.ai)

## About this repo

This repository contains the markdown source for [agentpatterns.ai](https://agentpatterns.ai). Content is published here automatically from a private source repo on each release.

Browse the folders to read any page as markdown, or visit the website for the full rendered experience with navigation, search, and cross-references.

## Reading offline

Clone the repo to read every page locally:

```bash
git clone https://github.com/agentpatterns-ai/website.git
```

The markdown renders directly in VS Code, Obsidian, and most editors.

## Requesting changes

Found an error, want to suggest an improvement, or have an idea for a new page?
