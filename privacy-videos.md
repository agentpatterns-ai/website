# Agent Patterns Videos Privacy and Terms

Agent Patterns Videos is an application that Agent Patterns operates to publish videos to its own [YouTube channel](https://www.youtube.com/channel/UCqdQ3uJMg95YVRg8ij5-3lQ). It is not offered to other users. Contact: [agentpatterns@gmail.com](mailto:agentpatterns@gmail.com).

## Privacy notice

Agent Patterns Videos uses YouTube API Services. The [Google Privacy Policy](https://www.google.com/policies/privacy) describes how Google handles data.

With the channel owner's authorization, the application accesses and stores Google OAuth credentials and the channel identifier. It also stores the videos, captions, titles, descriptions and settings it uploads, the identifiers YouTube returns, and upload records.

The application uses this information to verify the channel and upload videos and captions to it. It sends the information to Google and YouTube for that purpose. AI services from OpenAI and Anthropic prepare the video content.

Agent Patterns keeps this information while the application is in use. To ask a question, make a complaint or request deletion, email [agentpatterns@gmail.com](mailto:agentpatterns@gmail.com). You can also revoke the application's access through [Google security settings](https://security.google.com/settings/security/permissions).

## Terms of use

By using Agent Patterns Videos, you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). You must agree to the privacy notice above before using the application.

The application is provided as is, without warranties, to the extent the law allows.
